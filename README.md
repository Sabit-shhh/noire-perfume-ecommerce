# Noire: The Fragrance of the Night

### Project Overview
Noire is a conceptual e-commerce website designed for a luxury perfume brand. The aesthetic focuses on dark minimalism, gold accents, and a "midnight" atmosphere.

### Key Features
- **Dark UI:** High-contrast luxurious theme.
- **Responsive Design:** Works on desktop and mobile.
- **Product Showcase:** Highlights signature scents like Midnight Oud and Black Rose.

### Built With
- HTML5
- CSS3 (Flexbox/Grid)
- Google Fonts (Cinzel & Montserrat)
