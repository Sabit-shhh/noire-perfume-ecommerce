# Noire: The Fragrance of the Night

### Project Overview
Noire is a conceptual e-commerce website designed for a luxury perfume brand. The aesthetic focuses on dark minimalism, gold accents, and a "midnight" atmosphere.

### Key Features
- **Dark UI:** High-contrast luxurious theme.
- **Product Showcase:** Highlights signature scents like Midnight Oud and Black Rose.
- **HTML5:** Structured semantic code for a high-end shopping experience, including headers, product sections, and contact forms.
- **CSS3:** Centralized styling in style.css to maintain a consistent dark, luxurious aesthetic with gold accents.
- **Responsive Design:** Optimized for mobile and desktop using flexible layouts and max-width: 100% for high-resolution product imagery.
- **Navigation:** A sleek, global navigation bar featuring smooth interactive hover effects for a premium feel.

📂### Website Structure
This project consists of 5 interconnected pages, all sharing the unified Noire Dark Luxury aesthetic:
- **Home (index.html):** The "Fragrance of the Night" landing page featuring the Hero collection and brand mission.
- **Collection (collection.html):** An organized catalog of our signature scents and luxury sets.
- **Extra insights (info.html):** A visual showcase of our minimalist bottle designs and campaign photography.
- **The Alchemist (about.html):** Explains the craftsmanship, rare ingredients, and story behind the Noire brand.
- **Concierge (contact.html):** A sophisticated inquiry form for bespoke scent consultations and customer support.
